Playground

Experiments and prototypes for future games. Each lives in its own folder with a README. This page is maintained by Claude whenever an experiment is added.

1. Voice Lab

Synthetic character voices in the browser, Tomodachi Life style. Compare engines (Web Speech, espeak, SAM, babble, Piper neural), tune pitch / speed / tone / texture knobs, apply audio effects, build presets, stress-test crowds, and export voice JSON.

audiottsweb-audio

2. Lingo

Text-based language system: phrase templates with {placeholders}, a game-defined dictionary (races, spells, items, people) with singular/plural/possessive forms, personality knobs, trait tags, custom catchphrases, and a two-character conversation simulator.

textdialogpersonality

3a. Avatar 2D

Paper-doll character builder from stacked SVG layers: hair, eyes, brows, nose, mouth, body height / width, tops, bottoms, shoes, accessories. Presets, randomize, save in browser, export JSON.

svgcharacter

3b. Avatar 3D

Three.js character builder. Mii-style procedural body with a drawn face, plus a Quaternius (CC0) modular-mesh mode. Height / width, hair, outfits, idle + walk animation. Same JSON as the 2D version.

three.jscharacter

4. Name Forge

Procedural names for people, factions, regions, settlements, landmarks, artifacts and mottos across 12 races, each with its own language (sound rules + concept dictionary), meanings, plural/adjective forms and pronunciations. Exports Lingo dictionary entries.

nameslanguagestags

5. Item Vault

Tagged catalog of ~340 items (weapons, armour, vessels, regalia, lore, tools, instruments, food…) with race affinities and exclusives, plus a loot roller: material, quality, enchantment, artifact name, value and lore.

itemsloottags

Combined demo

One character sheet that ties the three together: an avatar with a voice and a personality that talks.

integration
