Asset Library

Scenery backdrops and map icons, in files, shared by every game here. loading…

Scenery

Each scene is one standalone .svg file with viewBox="0 0 100 100" and preserveAspectRatio="none", so it stretches to any box. The bottom third is kept simple: that is where the 3D characters stand. The night switch lays a dark wash over day scenes (scenes already drawn dark are left alone). Click a scene to enlarge it.

Map icons

Node markers for a world map, each a small .svg drawn in a -4 -4 8 8 box so it can be dropped into a map at any scale.

How to use

import { Assets } from '../assets/js/assets.js';

const assets = await Assets.open('../assets/');      // fetches data/manifest.json

// a backdrop element, ready to insert (adds the night wash for you)
backdropDiv.replaceChildren(await assets.sceneryElement('village', { night: false }));

// just the markup, if you build your own <svg>
const { inner, attrs, missing } = await assets.scenery('thornwood', { fallback: 'forest' });

// map icons
const icons = await assets.icons();                  // { combat: '<path …>', … }
node.innerHTML = icons[nodeType] || '';

// find scenes by tag
assets.listByTag('forest');                          // ['thornwood', 'forest', 'deepforest']
assets.sceneryIds(); assets.tags(); assets.sceneryInfo('cave');

Nothing throws. An id that is not in the manifest, or a file that has not been drawn yet, falls back to the scene you name in fallback and then to a plain gradient, so a game keeps running while art is still being made.
