Branch: `chibi26`. The original Avatar 3D milestones M0–M19 are recorded below. The owner later authorized game adoption and production deployment; see the rollout record at the end. No ordinary Git branch was pushed; the static site was published through its documented GitHub Pages release channel.

## M0 — baseline and version switch

**Status: complete.** The Avatar 3D page now has 2.5, 2.6, and side-by-side controls. `?v=2.5`, `?v=2.6`, and `?compare=1` select the view; the selected version is also kept in localStorage. The initial 2.6 factory is an explicit stub delegating to 2.5. Side-by-side builds the same look and clip twice in the same scene and camera. The live status line reports measured triangles, vertices, mesh/draw-call count, bones, and the current build time.

### Chibi 2.5 baseline

Measured from all 30 class looks in the current Emberveil roster, each with `body.v = 2.5`, freshly built in Node with the repository's Three.js loader. Build time is cold-process and includes geometry assembly; it varies by machine and code-cache state.

| Measure | Chibi 2.5 result |
|---|---:|
| Triangles | 5,632–8,306 across 30 classes; max is 8,306 (warrior is 8,306) |
| Meshes / draw calls | 1–2; 28 class looks use 2, 2 have no second material mesh |
| Bones | 24–32 |
| Build time | 29.97–123.67 ms; first cold build was 123.67 ms |
| Default plain look | 5,560 triangles, 2 meshes, 24 bones, 1.73 m |

`stats().meshes` is the count of merged skinned meshes, used here as the draw-call count for the character. The page additionally measures rendered vertices from the actor's live geometries.

### Standing rig measurements

`js/chibi26-metrics.js` reads world-space rig landmarks in metres. On the default 1.73 m 2.5 look: hip height / standing hip point 0.600 m; eye-bone height 1.380 m; shoulder joint width 0.515 m; shoulder-to-grip reach 0.453 m; hip-to-foot-joint leg length 0.543 m. Grip points are at `(-0.257, 0.540, 0.055)` and `(0.257, 0.540, 0.055)` m. Sole contact points use the rig's y=0 ground plane.

These are standing-rig readings, not a passed real-world fit check: seated hip position, seated eye height, human hand grip, and adult ranges have not yet been validated against the metric fit scene. The eye value is the eye bone landmark, not the eyeball surface. The 2.5 skeleton does not have a seated pose-specific measurement API.

## M1 — body and LODs

## M8 — keep the cloth map off skin and isolate the head-size dial

The texture review showed that the shared non-metal map was also multiplying the face, neck and exposed skin. The 2.6 cloth bucket now carries a per-vertex skin mask. Its shader bypasses the diffuse cloth map and uses a smoother roughness on those skin vertices, while garments keep the weave; the mask is retained through LOD clustering. This keeps the two merged draw calls. Low graphics still removes the maps entirely. The selector remains available through the shared factory, and no game source was changed.

The head-size correction is included here too: the leg solve now uses the race/form's neutral head scale as its height target. The head-size dial changes the head landmarks and geometry while leaving total character height fixed. Tests cover both the builder and the Avatar 3D slider.

## M9 — explicit surface tags and feminine travel outfit review

Removed color-based skin detection from mesh assembly. Exposed body skin gets explicit `surface: 'skin'` tags; face features use their `face:*` build stages to select smooth skin or hair surfaces. The previous check matched only the exact stage name `face`, while the face builder immediately refined it to `face:head`, `face:ears`, and other substages. That left the face unmasked and explains the cloth pattern on skin in the shared viewer. M11 finishes this path with stage-based face surface tags and a working map bypass. Garments remain cloth even when their color exactly matches the skin. The skin mask sets softer skin roughness within the same merged non-metal mesh.

Replaced the two overlapping chest spheres with a shallow, smooth deformation in the front torso surface. Shirt decals and shoulder straps query the same adjusted chest surface, so they follow the shape. The Human Wayfarer outfit combination was reviewed with feminine Round body, `travel_shirt`, and `bedroll_pack` from front and back: the shirt remains continuous and the pack straps sit over the chest without crossing the body. The bedroll sits at the back and stays visible from behind.
