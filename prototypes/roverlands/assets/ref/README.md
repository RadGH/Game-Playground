# Roverlands reference pictures

Turnaround sheets (side, front, top, 3/4) for the procedural three.js vehicle builders to LOOK at. These are references, not game art: never load them in the game. Each `<id>.png` is Codex's full-size 1536x1024 original; `<id>.webp` is a 1400 px wide copy (quality 80) for reading.

Made with Codex (`codex exec -s danger-full-access --skip-git-repo-check`, prompt on stdin, one job at a time in its own empty folder) on 2026-10-25. Every prompt is the shared preamble below followed by the vehicle line.

**Shared preamble:**

> You are making a REFERENCE SHEET (a model turnaround for a 3D modeller, not game art) for an original vehicle in a toy-like low-poly video game. Use your image generation tool to create ONE image, landscape 1536x1024 PNG, and save it in the current working directory as <id>.png. Do nothing else.
> 
> Layout: a turnaround sheet with FOUR views of the same vehicle arranged in a 2x2 grid: top-left SIDE view (true side elevation, facing left), top-right FRONT view (straight on), bottom-left TOP view (straight down, plan view), bottom-right a 3/4 perspective view. Plain flat light-grey background, flat even studio lighting, no shadows on the background, no scenery. Optional tiny view labels SIDE / FRONT / TOP / 3/4 are the ONLY text allowed: no logos, no brand names, no numbers, no writing on the vehicle.
> 
> Style: stylised low-poly toy-like 3D look — chunky, simple, readable shapes, flat-shaded facets, few small details. Clear base colour with darker trim, as described below.
>

The chibi is 1.73 m tall with a HUGE head (the head alone is about 0.6 m tall, a third of the body), hips at 0.6 m, very short stubby arms (0.41 m), short legs. Because of the big heads, seats sit LOW, steering wheels / handlebars / controls are pulled in close to the body, and any roofs, cages or canopies are TALL with plenty of headroom above the big heads. Keep the vehicle proportions consistent across all four views. The design is original (not a copy of any real or famous game vehicle).
