## The sim contract (js/sim/brawl.js — read its header)

```js
import { createBrawl, step, STEP, DEPTH } from './js/sim/brawl.js';
const G = createBrawl({ data, T, chapter: 'millbrook', heroes: [{ pid, name, cls, level, xp, gear, spells, look, ctrl }], seed });
step(G, { [pid]: { mx, mz, attack, heavy, jump, dash, block, grab, spell1, spell2, breaker } });   // 1/60 s
```
- `data` = `{ classes, enemies, chapters, items, story }` (the five JSON files). `T` = plain tuning values (`loadTuning` object).
- Edges (`attack heavy jump dash grab spell1 spell2 breaker`) are true on the step they were pressed (a press seen
  between steps must be handed to the NEXT step — never dropped); `block` is held; `mx/mz` in −1..1 (`mz` + = toward
  the camera = down the screen; `mz` − = up the screen / into the street).
- `G.events` holds this step's events (list in `EVENTS`). Loot/xp/gold/levelUp events carry `pid`.
- `G.over` + `G.outcome` ('won' | 'lost'). Retry after a loss: `createBrawl({ …, section: lostEvent.section })`.

### What the renderer and HUD may read (the VIEW STATE — the online mirror reproduces exactly these)
- `G.camX`, `G.phase` ('walk' | 'fight'), `G.secI`, `G.ch` (chapter def), `G.quakeT`, `G.t`, `G.over`, `G.outcome`.
- `G.heroes[]`: `id pid name cls level xp gear look x y z px py pz dir state anim hp max mp mpMax lives pickup
  invT buffs spells cds reviveT downClock gold`.
- `G.foes[]`: `id kind side team name boss x y z px py pz dir state anim hp max invT freezeT burnT` (side 'ally' = Grell
  fighting beside you).
- `G.props[]`: `id type ('crate'|'food'|'gold'|'weapon') x z kind pickup`.
- `G.shots[]`: `id x y z dir look team`. `G.zones[]`: `id kind x z r t delay team` (a zone with `delay` is a warning
  circle until `t >= delay`).
- `px/py/pz` are the positions at the previous step: the session sets them before every `step` so the renderer draws
  `lerp(p, now, alpha)` (lessons rule 28). The online mirror fills them from its interpolation.
- Animation: an entity's `anim` is its looping clip (`idle walk jump run block`); one-shot clips arrive as `move`
  events `{ id, anim, kind, dur, wind }` (play `anim` for `dur` seconds, its hit lands after `wind`). `hit` events flash
  and flinch; states `hurt air down out dead held thrown grab` each have a look (see render helper brief).

## Session contract (local: `js/game.js`, UI helper; online: `js/net/session.js`, net helper)

```js
const s = createLocalSession({ data, T, chapter, heroes, seed })   // or await createNetSession({ ... })
s.G                      // the view state above (the brawl itself locally; the mirror online)
s.tick(dtReal, inputsByPid) → { events, alpha }   // runs 0..n fixed steps; events = every step's events, in order
s.localPids              // the pids this device controls
s.paused / s.pause() / s.resume()                  // online: pause only opens the menu, the game keeps going
s.leave()
```

## Render contract (`js/render/`, render helper)

```js
import { createView, createPreview, renderPortrait } from './js/render/view.js';
const view = await createView({ canvas, data, quality: 'high' | 'low' });
view.setChapter(chapterId)          // builds that chapter's street + backdrop (async-safe: returns a promise)
view.update(G, alpha, dtReal)       // every animation frame: syncs actors/props/shots/zones with the view state
view.handle(events)                 // fx + one-shot clips + damage numbers for this frame's events
view.project(x, y, z) → { x, y, visible }   // world → CSS px in the canvas (HUD pins, off-screen arrows)
view.resize(); view.dispose()
view.scenic(on)                     // map/creator backdrops: slow pan over the current chapter, no actors
view.setShot({ pos, target, fov } | null)   // a directed camera (story stage, review pages); null gives it back
const st = createStage(view, { data, scene, chapter, where, heroes })   // story scenes acted in the street (stage.js):
st.line(i); st.reveal(n); st.safe({ top, bottom }); st.wide(); st.update(dt); st.dispose()   // directions: top of js/ui/story.js
const p = await createPreview(canvas);  p.setLook(look, cls); p.setAnim('idle' | 'cheer' | …); p.spin(on)
const url = await renderPortrait({ look } | { creature }, { size: 128 })   // portrait drawn from the 3D model
// hands.js: two-handers held in both hands in every clip (left-hand reach + w2_ strikes + w2s_ staff carries) and
// WEAPON_LENGTH (least drawn length per weapon kind, also used by item icons); actors.js bodyShape: form decides the chest
// Acts II/III: themes-acts.js (18 streets, built with themes.js K), fx-acts.js (strips 'col'/'row', zone looks, hazard
// patches, rise/expose/sky/gust/calm/enrage/burst; ZONE_LOOKS), actors.js giants (def.backEdge: behind the street,
// lunging to e.x/e.z with a gold ring while `part` is down) + render hints (ghost/glass/veins/pale/wet/tint),
// view.js builds Ossmara's fly-over body with a sky chapter. View state read: foes' hidden, part, homeZ, state rise/calm.
```

## Acts II/III (round 2)

- **Data:** `data/acts.json` (acts, routes, choice scenes, endings, 18 chapters) + `data/story-acts.json` (speakers,
  scenes, banter, boss lines) are kept apart from the Act I files and merged once at load by `mergeActs(data)`
  (`js/sim/route.js`) — in `js/main.js`, `server/data.js` and every test loader. A loader that forgets it sees only Act I.
- **The road:** `routeFor(data, choices)` = Act I + `routes.act2[act1]` + `routes.act3["act1.act2"]`. A chapter's
  `path` ("free", "free.bond"…) says which road it is on; `progressOf` gives `reached` = first chapter not done on that
  road. `choiceAt` finds the chapter whose outro holds a choice; `applyChoice` sets it (a new Act I choice clears Act II).
- **Pre-boss hold:** a chapter with `bossScene` stops the sim before its boss (`G.hold`; nothing moves, no clock) until
  `releaseHold(G)`. Locally `js/ui/bossscene.js` plays the lines and releases; online only the host's `release`
  message counts, and the server releases by itself after 8 s + 6 s per line (60 s at most).
- **Giants:** enemies with `backEdge: true` live behind the street and expose parts to be hit (`js/sim/big.js`, header).
  Chapter `sky` = Ossmara's fire on foes only, warned first.
- **Gear:** loot uses the chapter's `tier` (6–11 for Acts II/III), not its place in the list; levels go to 20, the 4th
  class move opens at 13.
