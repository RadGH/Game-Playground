# shared/ — helpers every playground page can import

The list below was convention 3 in `playground/CLAUDE.md` until 2026-11-11, kept word for word. Add new shared helpers here.

3. **Shared helpers** live in `shared/`: `style.css` (dark minimal UI), `ui.js` (knobs, selects, panels, JSON export/import, seeded rng), `store.js` (namespaced localStorage), `tooltip.js` + `tooltip.css` (the shared tooltip engine: `installTooltips()` once, then `data-tip="text"`, `data-tip-html` or `data-tip-render` on any element — 150ms delay, flips at the screen edge, keyboard-focus friendly, no library), `langdebug.js` (language debug mode: click words in spoken lines to see/override pronunciations, export/import/submit), `voices.js` (party voice system: a timbre per class/role on our formant engine, varied by seed — `voiceFor({ role, gender, seed })`), `format.js` (one number formatter for every screen: `fmt` at most two decimals, `hp` whole, plus `pct`/`sign`/`range`/`secs` — nothing rendered should ever read "25.02000000000001"), `character-schema.md` + `character.example.json` (the shared character JSON that experiments can read/write). Sound is not in `shared/` but works the same way: `sfx/js/sfx.js` (`Sfx.create({ method })`, `play(id, { pan })`) is the one place any page gets sound effects from, and `prototypes/emberveil/js/sfx-bridge.js` shows how to hook a game without editing it.
   **Accounts** (2026-10-23): `rgs-account.js` (the games.radgh.com account client: `account.user()`, `signIn`, `ticket(game)`, QR `pair(game)`) + `rgs-signin.js`/`.css` (`openSignIn()` box with QR code, `accountButton()`) — sign-in is always optional; read `shared/RGS-ACCOUNT.md`.
   R16 also added `rewards.js`'s **opt-in chooser** (`spec.choose` — three cards, pick one; default-off, so Emberveil's loot popup is byte-identical) and, in `avatar-3d/js/chibi2-motion.js`, `CHIBI2_RIDE_ANIMS` (`boat`, `sit`) on its own opt-in list.

Also here: `dialog.js` + `dialog.css` (in-game ask / tell / askText / showCode — never browser alert/confirm/prompt), `whats-new.js`/`.css` (changelog button), `credits.js`/`.css` + `credits.json`, `rgs-cloudsave.js`, `test/screen-text.js` (rendered-text check). Accounts: read `RGS-ACCOUNT.md`.
