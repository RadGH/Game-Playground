**Thousandvale** (2026-10-04 →): an online RPG in one huge walkable world shared by up to a thousand players — Farhold's 30 classes, 180 skills, talents, perks and loot in a province of 2×2 km zones, each with towns, farms, a fort, a multi-floor dungeon, rares, zone events and hidden treasure; parties, guilds, trading, mail, friends, mounts. **A real game server, not static files**: Node + WebSockets + Postgres, authoritative sim in `js/sim/`, pure shared rules in `js/rules/`, client in `js/client/`. **Stable on port 8490, dev on 8491** (never 8400/8401); the public home is **https://thousandvale.games.radgh.com/** on the RGS droplet (`~/claude/docs/rgs.md`), kept in `data/live-links.json` and shown as the home page's separate "Live link" button (the old quick tunnel was stopped 2026-10-14). Build streams, contracts between them and sudo requests live in `docs/requests.md`; **`docs/PLAN.md` is the spec** (§0 = the rules it never breaks: go anywhere, something new every ~45 s of walking, open every chest), `docs/CHANGELOG.md` the history, `ops/` + `tools/README-servers.md` the server notes, `docs/HOSTING.md` the VPS plan. Publish with `prototypes/thousandvale/tools/publish-thousandvale.sh`. **2026-10-14**: every non-gear icon is Codex art from `icons/` (gear icons are worn by a plain mannequin: chibi2 `{ mannequin: true }`), and every class has **signature spell effects** (`js/client/sig-looks.js` pure + `sig-fx.js`, one instanced draw) with Settings → Graphics → **Spell effects** Enhanced/Standard/Reduced/Off (`js/client/fx-level.js`). **Expansion 1 (2026-10-14, `docs/EXPANSION-1.md`)**: the world is islands (`CONTINENTS` in `tools/lib/world-core.mjs`; outside them is open sea), Torbor Downs is one, and **Vharlen, the Burning Isle** (levels 10–20, 3×3 volcanic zones, the `vharl` culture, 13 island-only monsters in `data/rules/monsters-tv.json`, hot springs / geysers / lava vents / ashfall in `js/sim/hazards.js`) is reached only by ship (`js/sim/ships.js`, Gullwick ↔ Port Vharl); per-province data is `data/provinces/<province>-<file>.json`, and after a Vharlen re-bake run the content chain then `tools/content-hazards.mjs` last. **ON HOLD since 2026-10-13** after ten play-test rounds and a wrap-up (31 classes with the Starcaller, ten professions, economy re-fit; resumed 2026-10-15 for play-test 11, which added a 32nd class, the Star Blade): **read `docs/ON-HOLD.md` first when it is resumed**; the to-do list is `public/todo.html` (players; linked from the title screen, What's new and the games.radgh.com card) + `~/claude/agent/mmo/todo-after-pt12.md` (Claude) — keep them in step; play-test 12 shipped 2026-10-20, the Torbor Downs regeneration is parked on branch `wip/torbor-regen` — where it stands, how to pick it up, and everything parked (node rarities, the rest of professions, 11 more provinces, a real-iPhone pass).
