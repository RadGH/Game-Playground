    About the frames

    Desktop and Laptop are the game as it is today. iPhone 15 Pro: “Today” is the same code on a phone-sized screen; “Proposed” switches on the phone layout (a real stylesheet and touch layer that the game itself keeps off until you approve it). Controller: the desktop interface as a gamepad player sees it — this part is live in the game now.

    Everything in a frame can be clicked. Requests that change things (wear, buy, accept) are sent to a recording and go nowhere.
