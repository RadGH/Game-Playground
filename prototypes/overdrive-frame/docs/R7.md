## Contract between A and B: weapon spec fields

`loadout.js weaponSpec` builds the spec; part mods (lead) and new parts (helper B) set these fields; `weapons.js` /
`mission.js` (helper B) make them happen. Every field is optional; absent = today's behaviour.

| Field | Meaning |
|---|---|
| `dtype` | adds `'cryo'` (status `chill`: slows; 3 stacks within 3 s = `frozen` 1.5 s, can't move or attack) and `'void'` (ignores resistances and front armour; status `rift`: pulled a little toward the hit point). Existing: kinetic, energy, explosive, fire, electric |
| `count`, `splash`, `pierce`, `status` | as today (mods change them) |
| `ricochet` | n: a bullet that hits bounces to the nearest other enemy within 3 tiles, n times |
| `chainOnHit` | { jumps, chance }: a hit sparks a lightning arc to `jumps` enemies nearby (electric, 40% of the hit) |
| `seek` | rad/s: plain bullets curve gently toward the nearest enemy in front |
| `echo` | 0..1: each shot fires again 0.3 s later at this fraction of the damage |
| `vortex` | { r, t, pull }: an impact leaves a gravity well (r tiles, t seconds) that drags enemies in |
| `cluster` | n: a blast throws n bomblets that burst 0.4 s later (35% damage each, 0.5-tile blast) |
| `napalm` | seconds: a blast leaves burning ground (fire, burns what stands in it) |
| `leech` | 0..1: this fraction of damage dealt repairs the shooter |
| `overkill` | 0..1: a kill bursts for this fraction of the killing hit (0.8-tile blast) |
| `knock` | as today, mods can raise it |

New weapon `kind`s are helper B's to add (spec `kind` + `KIND_MAP` row + parts.json part + Mech Kit model + look).

## Contract between A and D: frame lines

Every head / core / arms / legs / booster part carries `line` (e.g. `"wisp"`); `js/sim/frames.js` (lead) lists each
line: maker, name, look sentence, set bonus (`js/sim/frames.js` SETS). Existing lines: Wisp/Stride/Halberd (Celerity), and the tier-1/2/3
families of the others (helper D adds `line` to them too). New parts go in `mechkit/data/parts.json` and
`mechkit/js/parts/<maker>.js`; tiers spread 1–3 so they turn up at every rank.
