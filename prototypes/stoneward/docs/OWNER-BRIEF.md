# Owner brief (Radley, 2026-11-03) — verbatim

> I'd like to plan a new game with a similar pixel physics engine to Kindlewild, but generates an entire planet like farhold and wraps around and lets you zoom out very far. There should be different size worlds from x-tiny to x-large. The game should work as a city builder with a research system to upgrade things over time and defend your castle from other factions, neutral hostiles, raids etc. It should be more of a city sim than an RTS. As migrants arrive they build nearby houses. As the city grows, houses upgrade or merge into larger houses. It should be focused on medieval castle era theme and have some resources like iron, wood, coal. As you build your city it develops needs and so you need to gather resources from outside your city walls. You can build roads that affect travel time, and resources have to travel back to your base similar to the mining industry from cities skylines. The world should grow naturally, but the player can also spend resources to build deliberately from a build menu. There should be various screens to see info about your city, and data layer views to view different information. You should be able to hire guards of different types and give them patrol routes. Patrol routes would increase safety of an area, like how putting a police station turns houses from red to blue or green in cities skylines. Without protection you get attacked, so remote outposts need their own stationed defense. However I think it's a balancing act. I want to be able to build walls similar to Kindlewild, by drawing lines. Walls should be destructible by certain things like catapults, lava, but should have some durability before they fail. There should be attacks from monsters requiring you to set up defenses. Cities should grow and become very large, and make use of lighting effects to light up at night. Kindlewild currently does not have much multi-tile-high structures but I think this game would warrant them. There should be physics when a wall or building is destroyed and debris should remain for a time. Let's start by asking questions. Start by asking me questions of your choosing.
