Simulated fights

The meter is a plain record log. Any game feeds it one record per hit or heal: who, whom, how much, through what (weapon, skill, effect), damage type, crit, overkill, killing blow. The Emberveil 2 prototype feeds it from its combat simulator.

How to embed

import { Meter } from './meters/js/meter.js';
import { renderMeter, METER_CSS } from './meters/js/meter-ui.js';
const m = new Meter(); m.startFight('goblins');
m.record({ t, source, sourceName, target, targetName, kind: 'damage',
  amount, overkill, crit, dtype: 'fire', via: 'skill:fireball',
  viaName: 'Fireball', itemId, killingBlow, tags: ['blocked'] });
m.endFight(); renderMeter(m, container, state);
