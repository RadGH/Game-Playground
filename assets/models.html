Space Models

Procedural Three.js objects for orbit and deep space: planets with real map textures, every star class, belts, craft and stations. Universe loading…

Models

Every builder in assets/js/space-models.js, each in its own scene, turning. Drag a tile to orbit it. The two selects at the top rebuild the planet and the star with a different kind. Planets here use the library's own blotchy texture; hand createPlanet a texture set from universe/js/texture.js and you get the real surface map instead.

How to use

import { createSpaceScene, createPlanet, createStar } from '../assets/js/space-models.js';

const view = createSpaceScene(container);            // renderer + camera + orbit controls + loop
const star = createStar(starRecord, { radius: 1.2 });
view.scene.add(star.group); view.addTicker(star.update);

// a planet with its real surface map (needs the universe library)
import { generatePlanetMap } from '../universe/js/planetmap.js';
import { planetTexture } from '../universe/js/texture.js';
const world   = generatePlanetMap(planet);
const texture = planetTexture(planet, world, { size: 1024 });
const globe   = createPlanet(planet, { texture, radius: 1 });
view.scene.add(globe.group); view.addTicker(globe.update);

// or by manifest id
import { createSpaceModel, SPACE_MODEL_IDS } from '../assets/js/space-models.js';
const ship = createSpaceModel('ship_hauler');

Every builder returns { group, update(dt, t), dispose() } — the same shape the creature models use, so the same scene code drives both.
